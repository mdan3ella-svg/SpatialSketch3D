## Identity

The visual mark is a continuous spatial S curve with a small secondary orange geometry cue. The primary UI is studio white, paired with deep graphite, turquoise, and restrained technical orange. Use **Spatial Sketch 3D** in headings, web page titles, installer names, documentation, launchers, and export metadata. The application should not suggest legal trademark registration before independent trademark clearance.
