# Changelog

## v2.4 — Motion Lab
- Implemented template-based skeleton and per-vertex smooth/rigid skin binding.
- Implemented editable bone rotations, armature drawing and bone picking.
- Implemented FABRIK IK solver, editable targets, animated IK keyframes and IK marker deletion.
- Implemented native multitrack NLA clip blending with mute/solo/weight and time controls.
- Implemented deterministic fixed-step translation dynamics with ground and AABB contacts.
- Added GLB skin export with weight attributes, joint hierarchy, inverse bind matrices and sampled skeletal animation.
- Added offline H.264 MP4 output via supported browser encoders, preserving WebM fallback.
- Added Motion Lab responsive inspector and native editable motion demonstration.
- Preserved all existing v2.3 modeling, drawing, materials, camera, rendering and object animation capabilities.

## v2.3 — Timeline repair
- Previous native keyframe editing, timeline playback, camera tracks, GLB transform animation and WebM recording.
